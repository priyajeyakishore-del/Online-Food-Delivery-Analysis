# Online Food Delivery Analysis

**Data Analytics Project | Python • SQL • Power BI**

## Project Overview

This project analyzes online food delivery operations to understand customer ordering patterns, restaurant performance, delivery efficiency, cancellations, and revenue trends.

The objective is to transform raw operational data into meaningful insights and business recommendations using Python, SQL, and Power BI.

## Tools & Technologies

- **Python:** Pandas, NumPy, Matplotlib, Seaborn
- **SQL:** Data querying, aggregations, grouping, and business analysis
- **Power BI:** Interactive dashboards, KPI cards, DAX measures, and visualizations
- **Jupyter Notebook / VS Code:** Data analysis and development
- **Git & GitHub:** Version control and project documentation

## Project Workflow

1. Dataset inspection and data understanding
2. Data quality assessment and cleaning
3. Exploratory Data Analysis (EDA)
4. Univariate, bivariate, and multivariate analysis
5. SQL-based business analysis
6. Power BI dashboard development
7. Business insights and recommendations

## Power BI Dashboard

The dashboard contains six pages:

1. Executive Overview
2. Customer & Order Analysis
3. Delivery Performance
4. Restaurant & Cuisine Performance
5. Operational Insights
6. Revenue & Profit Analysis

## Key Business Questions

- What proportion of orders are delivered versus cancelled?
- Which cities and cuisines generate the most recorded revenue?
- How do ordering patterns differ across customer age groups and days?
- How are delivery time, distance, and customer ratings related?
- Which payment methods are most commonly used?
- What are the most frequently recorded cancellation reasons?
- How do discounts relate to order value and recorded profit?

## Data Quality Considerations

The analysis considers missing values, inconsistent data types, incomplete cancellation reasons, and missing financial and rating information. These limitations are important when interpreting the results.
